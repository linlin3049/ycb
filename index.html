遗传病推断：全概率贝叶斯框架（可直接编码）

目标：不做近似排除，保留极小先验概率，输出所有基因型可能性的严格后验分布。

Bayesian NetworkVariable EliminationLog-Probability

一、核心建模（离散贝叶斯网络）

  • 节点：每个个体一个随机变量，取值为该遗传模式下的基因型。
  • 边：父母 → 子女，表示等位基因传递。
  • 因子：奠基者先验 + 家庭传递CPT + 表型似然。
  • 输出：每个个体基因型后验 P(g_i|E) 与模型证据 P(E|M)。

二、模式定义（AR / AD / XR / XD / Y）

模式基因型域完全外显率规则（患病）
ARAA, Aa, aa仅 aa 患病
ADAA, Aa, aaAA 或 Aa 患病
XR女: XAXA/XAXa/XaXa；男: XAY/XaY女仅 XaXa；男仅 XaY
XD同 XR女 XAXA/XAXa；男 XAY 患病
Y男: YA/Ya；女固定正常男仅 Ya 患病

三、先验与传递

奠基者先验（Hardy-Weinberg）：

常染色体：P(AA)=(1-f)^2, P(Aa)=2f(1-f), P(aa)=f^2

伴X与伴Y按性别定义对应先验。家庭内子代CPT按孟德尔分离自动枚举生成。

四、证据似然

每个个体观测表型 E（患病/正常），映射为：

P(E|g)=penetrance(g)（患病）或 1-penetrance(g)（正常）

完全外显下，不相容基因型似然 = 0（硬约束）。

五、推理算法（推荐变量消元）

for mode in [AR, AD, XR, XD, Y]:
  define genotype domain for each person
  factors = []
  add founder-prior factors
  add transmission factors P(g_child | g_father, g_mother)
  add phenotype likelihood factors P(E_i | g_i)

  posterior(targets) = variable_elimination(factors)
  log_evidence(mode) = log Z

if compare_modes:
  P(mode|E) = softmax(log_evidence(mode) + log prior(mode))

小家系（≤20人）可直接全状态枚举，保证严格精确并覆盖所有极小概率分支。

六、数值稳定性（极小概率）

  • 统一在 log 空间计算联合概率：log_joint = Σlog(prior)+Σlog(CPT)+Σlog(likelihood)。
  • 归一化使用 log-sum-exp，防止下溢。
  • 不引入“近似排除规则”，仅由证据似然决定是否为零。

七、输出格式建议

  • 每种遗传方式：log证据、证据后验概率、每个目标成员的基因型后验分布。
  • 统一展示“前3高概率基因型 + 完整分布JSON”，便于前端与API对接。
  • 可增设参数：不完全外显率、de novo突变率、纯合致死惩罚项。
